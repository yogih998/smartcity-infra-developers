# Smart City Infra Developers

Website for Smart City Infra Developers, a real estate developer in Hyderabad (smartcityinfradevelopers.com).

`main` holds the published website. It is empty while the new version is being built.

| Where | What |
|---|---|
| `v2` branch | New version, in progress. Merged into `main` when ready. |
| `v1-backup` branch | Previous website (static HTML), restored from the Internet Archive. |
| `v1` tag | Fixed snapshot of the previous website. |

To look at the previous website: `git checkout v1`
